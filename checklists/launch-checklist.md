# Launch Checklist

## Config

- [ ] `site.config.ts` valid
- [ ] `id` matches directory
- [ ] domains unique
- [ ] canonical host set
- [ ] primary tool known
- [ ] lifecycle status correct

## Content

- [ ] default locale home approved
- [ ] title and description present
- [ ] examples/use cases included
- [ ] FAQ or troubleshooting included where useful
- [ ] privacy/limitations explained
- [ ] AI-assisted content reviewed

## SEO

- [ ] canonical correct
- [ ] hreflang correct
- [ ] x-default correct if used
- [ ] sitemap only includes indexable pages
- [ ] robots points to production sitemap
- [ ] structured data allowed and valid

## Tool

- [ ] happy path works
- [ ] error states work
- [ ] mobile tested
- [ ] input limits enforced
- [ ] analytics redaction verified

## Ads

- [ ] ads disabled unless monetizable
- [ ] no ads near primary action buttons
- [ ] ad labels not misleading
- [ ] no ads on under-construction pages

## Deploy

- [ ] preview deploy passes
- [ ] production domain configured
- [ ] secrets present
- [ ] homepage 200
- [ ] robots 200
- [ ] sitemap 200
- [ ] selected site identity verified
