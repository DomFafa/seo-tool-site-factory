# Content Review Checklist

- [ ] Page primarily helps the user, not only SEO.
- [ ] Tool is usable before long SEO text.
- [ ] Content explains what the tool does.
- [ ] Content includes real examples.
- [ ] Content is not copied across domains with only keyword swaps.
- [ ] Localized page reads naturally in its language.
- [ ] Machine translation has been reviewed.
- [ ] AI-assisted content has been fact-checked.
- [ ] Privacy and limitations are visible when relevant.
- [ ] `contentStatus` can be set to `approved`.
