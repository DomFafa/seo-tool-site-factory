## Convert an image to PNG

This tool converts common image files to PNG format in your browser. Choose an image, wait for the conversion, and download the PNG result.

## Supported formats

The v1 browser converter supports JPG, PNG, and WebP input. HEIC and advanced batch processing can be added later if needed.

## Privacy note

The v1 conversion is client-side. Your selected image is not uploaded by this tool.
