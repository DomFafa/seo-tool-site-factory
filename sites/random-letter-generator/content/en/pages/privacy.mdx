## Privacy

Random Letter Generator is designed so the core letter generation happens in your browser. The selected mode, custom alphabet, and generated output do not need to be sent to a server for the tool to work.

## Analytics policy

Analytics, when enabled for a reviewed production site, should use safe fields only. Raw custom letters, generated output, typed text, uploaded content, and other user-provided values must not be included in analytics events.

## Local processing

The browser normalizes the letter set, applies no-repeat rules, generates letters, groups the result, and formats the copy output locally. Copying results uses your browser's clipboard features.

Email `contact@random-lettergenerator.com` for privacy questions, correction requests, or accessibility issues related to Random Letter Generator.
