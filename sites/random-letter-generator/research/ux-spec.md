# UX Spec

## First Viewport

The first viewport should feel like a compact Sejda-style utility: centered headline, short subtitle, immediate primary tool, soft green action color, coffee/brown accents, and a tan wave band behind the tool.

## Task Path

- Presets are one tap.
- Count and no-repeat controls are visible without scrolling on desktop.
- Generated letters appear as large tiles.
- Copy controls stay close to the result.

## Mobile

Controls stack into one column. Letter tiles keep stable dimensions. Text must not overflow buttons or cards.

## Empty, Result, and Error States

- Empty state should show a starter A-Z output.
- Result state shows status and copy-ready text.
- Error state explains what to fix, especially impossible no-repeat count.

## Accessibility

All controls need visible labels, keyboard focus, and aria-live result messaging.

## Ad Restrictions

Ads remain disabled. If added later, no ad slot can be near Generate, Copy, Retry, or primary result actions.
