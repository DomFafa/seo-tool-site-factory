# SEO Spec

## Metadata

Title: `Random Letter Generator - Pick Letters, Teams, and Sequences`

Description: `Generate random letters from A-Z, vowels, consonants, or a custom alphabet. Choose repeats, grouping, casing, and copy format.`

H1: `Random Letter Generator`

Hero subtitle: `Generate one letter or a clean list of random letters for games, classrooms, naming drills, alphabet practice, and test data.`

## Static Content Structure

- H2: Generate random letters for real tasks
- H2: Useful random letter examples
- H2: Choosing the right letter mode
- H2: FAQ

## FAQ Targets

- Can I generate more than one random letter?
- Can I generate letters without repeats?
- Can I use only vowels or consonants?
- Can I use custom letters?
- Are the generated letters truly random?
- Are my custom letters saved?

## Structured Data

Use `WebSite`, `WebPage`, and `SoftwareApplication`.

## Indexing

Keep `index: false`, `allowIndex: false`, and lifecycle `draft` until launch review, content review, design review, UI similarity review, performance audit, and SEO audit complete.

## Avoidable Before-build Requirements

- Do not hard-code canonical URL in Astro pages.
- Do not include raw custom letters or generated output in analytics.
- Make the primary tool and static explanatory content present in generated HTML.
- Keep ads disabled and never place ads near Generate or Copy.
