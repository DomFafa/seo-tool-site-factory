# Design Review

Status: approved for implementation

## Review

- Visual direction is specific to the user's Sejda reference and avoids a generic gradient/card layout.
- Palette uses green and coffee/brown with warm neutrals, not a one-note purple/blue theme.
- Hero is concise and utility-first.
- Wave background is contextual and not a decorative orb/blob.
- UI controls match the domain: segmented presets, checkbox/toggle, numeric input, select menus, and direct command buttons.

## Risks To Check After Build

- Wave band must not obscure text or primary controls.
- Button labels must fit on mobile.
- Letter tiles should not resize the layout when output count changes.
- Tool must remain usable without reading explanatory text.
