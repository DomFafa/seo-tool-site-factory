## Open iPhone HEIC photos when apps say the file is not supported

HEIC files are common when photos come from an iPhone or iPad, but Windows Photos, Android apps, CMS forms, email clients, and older desktop software still often expect JPG or PNG. This tool is built for the quick moment when you need to inspect a `.heic` or `.heif` image and move on.

The selected file is decoded locally in your browser. After the preview appears, you can save a JPG or PNG copy for tools that do not accept HEIC.

## When this helps

- You downloaded an iPhone photo on Windows and the default viewer will not open it.
- A website asks for JPG or PNG, but the image on your device is HEIC.
- Someone sent a `.heif` file and you want to check what it contains before converting it.
- You want to avoid uploading private IDs, receipts, legal photos, or client images to a cloud converter.

## Format choices

Use JPG when you need the safest format for uploads, Windows, Android, email, printing, or support tickets. Use PNG when you need a lossless copy for documentation, design workflows, or screenshots. Keep the original HEIC file when storage efficiency and Apple Photos compatibility matter.

## Privacy boundary

The file picker hands the image to this page in your current browser session. The tool does not need a server upload for the open, preview, or export flow. Analytics, when enabled, must only use safe fields such as file type bucket and success state, not the file name or image content.
