## How to use the anagram solver

1. Type the letters you want to rearrange.
2. Set the minimum word length.
3. Add optional filters if you know part of the answer.
4. Review the possible words in the result area.

## Filter examples

Use **starts with** when a puzzle already gives you the first letter. Use **ends with** for crossword-style clues. Use **contains** when you know a letter or letter group must appear somewhere in the answer.
