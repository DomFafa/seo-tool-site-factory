- Research status is recorded as `READY`, `READY_WITH_FALLBACK`, `BLOCKED`, or `NOT_ATTEMPTED`.

- Launch status is recorded as `DRAFT_ONLY`, `READY_FOR_REVIEW`, or `READY_TO_INDEX`.
- Research readiness, design specificity, and launch readiness are scored 0-10.
- Claims used to pass a gate have evidence: captured rows, attempted URLs, screenshots/artifacts, command output summaries, or report paths.

## Functional Tests

| Test | Input / Action | Expected output / behavior |
|---|---|---|
| Basic weighted grade | Homework 20% score 90, quizzes 20% score 80, exams 40% score 85, final 20% score 0 excluded | Current grade is calculated from included categories and explains included weight. |
| Full 100% weights | Four valid rows totaling 100% | Result shows exact weighted course grade with no missing-weight warning. |
| Underweight categories | Rows total 75% | Result appears with warning that only 75% of course weight is represented. |
| Overweight categories | Rows total 120% | Warning appears that weights exceed 100%; final interpretation is blocked or clearly labeled. |
| Invalid input | Score `abc` or weight `-10` | Field is marked invalid and result excludes/block invalid row. |
| Zero-weight row | Category weight 0 with score 100 | Row is allowed but does not affect grade; note explains this. |
| Blank score | Category has weight but no score | Treat as missing, not zero, unless user explicitly includes it as zero. |
| What-if target | Current grade data plus target 90 and final weight 20 | Needed final score is shown, including impossible/secured states. |
| Copy result | Click copy | Clipboard contains output summary and success state appears. |
| Clear/reset | Click clear | Inputs return to starter state or empty state. |
| Example chip | Click example | Rows and output update to realistic preset. |
