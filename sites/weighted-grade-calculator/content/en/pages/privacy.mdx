## Privacy overview

WeightedGrade is built so the grade calculator runs locally in your browser. The tool does not need an account, login, upload, or server-side grade processing.

## Grade inputs

Raw grade inputs are not collected by this tool. This includes:

- Category names.
- Category weights.
- Scores.
- Target grades.
- Remaining-weight values.

These values are used in your browser to calculate the result you see on the page.

## Analytics

If analytics are enabled in the future, events should only use safe fields such as locale, action, and result status. Raw grade inputs, typed category names, and scores should not be included in analytics events.

## Contact

For privacy questions or correction requests, contact contact@weighted-gradecalculator.com.
