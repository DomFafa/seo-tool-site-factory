## Frequently asked questions

### Is this a real font?

No. The tool converts supported letters into Unicode characters that look like cursive or script text. You can copy and paste the result like regular text.

### Why do some letters look different?

Unicode script characters are not identical to handwriting fonts. Some apps also use different fallback fonts, so the style can vary slightly.

### Can I use cursive text on social media?

Usually yes, but support depends on the platform. Always paste and preview the text where you plan to use it.

### Does the tool save my input?

No. The conversion runs in your browser and this tool does not send the text you enter to a server.
