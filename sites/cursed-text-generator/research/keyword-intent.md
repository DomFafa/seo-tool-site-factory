# Keyword Intent: cursed text generator

## Metadata

- Site ID: cursed-text-generator
- Primary keyword: cursed text generator
- Category: generator
- Locale: en
- Search market: US
- Research date: 2026-04-30

## User Job

> Paste normal text and instantly create creepy, glitchy, cursed/Zalgo-style Unicode text that can be copied into social posts, chat, usernames, or horror-themed content.

## Expected Action

> Enter text, choose or tune cursed intensity, preview the output, then copy it.

## Search Intent

### Primary intent

Immediate tool use. The user wants a copy-ready cursed text output, not a long article.

### Secondary intents

- Learn whether cursed text, glitch text, hacked text, void text, and Zalgo text mean the same thing.
- Find platform-safe output for Discord, TikTok, Instagram, Reddit, games, and usernames.
- Control readability with light/medium/heavy intensity or top/middle/bottom mark controls.
- Clean cursed text back into readable plain text.

### Non-intents

- Image generation.
- Harmful hacking or malware.
- Installing a real font file.
- Full typography editing.

## Standalone Site Decision

| Factor | Max | Score | Notes |

| User task clarity | 25 | 24 | Very clear paste-transform-copy task |
| Competitor weakness | 20 | 15 | Bing top results rank with dated UI, catalog noise, ads, or missing cleaner mode |

| Maintenance simplicity | 15 | 14 | Unicode combining-mark generation and cleanup are simple, local, and testable |
| Total | 100 | 86 | Build standalone site |

Decision: `standalone-site`

Reason: The keyword has clear tool intent, visible Bing demand, simple implementation, and concrete competitor gaps. It should remain a standalone site, but the page must be more useful than a generic Zalgo clone.
