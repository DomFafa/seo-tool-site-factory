# Acceptance Tests: Cursed Text Generator

## Functional Tests

| Test | Input / Action | Expected output / behavior |
|---|---|---|
| Basic cursed generation | `hello` with Medium preset | Output differs from input and contains Unicode combining marks |
| Empty input | empty string | Output is empty, copy is disabled or non-primary, examples remain visible |
| Light preset | `hello` with Light preset | Output remains readable and has fewer combining marks than Medium |
| Heavy preset | `hello` with Heavy preset | Output has more combining marks than Medium but remains contained in output panel |
| Advanced top control | Increase top marks | Output adds more above-letter marks |
| Advanced middle control | Increase middle marks | Output adds more strike-through/middle marks |
| Advanced bottom control | Increase bottom marks | Output adds more below-letter marks |
| Multi-line input | `hello\\nworld` | Output preserves line break |
| Unicode / emoji input | `hello 👻` | Emoji is preserved and UI does not break |
| Existing cursed input cleanup | paste cursed/Zalgo text in clean mode | Combining marks are stripped and readable text remains |
| Very long input | long social-post-sized text | Tool stays responsive or shows a warning/cap without crashing |
| Copy result | Click copy | Clipboard contains output and success state appears |
| Clear input | Click clear | Input and output reset, settings remain or reset as specified |
| Reset settings | Click reset settings | Preset returns to Medium and advanced controls return to defaults |
| Example chip | Click `do not open` | Input and output update |
