## What is cursed text?

Cursed text is normal text distorted with Unicode combining marks. Those marks stack above, through, and below letters, creating the creepy effect often called Zalgo text, glitch text, corrupted text, hacked text, or void text. This generator keeps the task simple: type a phrase, choose an intensity, tune the mark positions if needed, and copy the result. It also includes a clean mode that strips combining marks from cursed text when the output is too intense or hard to read.

## Cursed, Zalgo, glitch, and hacked text

These names usually describe the same technical trick. Zalgo text often uses heavy marks in every direction. Glitch text can be lighter and more readable. Hacked or corrupted text is the same visual style used for game names, ARG clues, horror posts, and dramatic chat messages. The best setting depends on where you plan to paste it.

## Platform notes

Discord, Reddit, TikTok, Instagram, and gaming profiles can render cursed text differently because each app handles Unicode marks in its own way. Light or medium intensity is usually safer for usernames, bios, and short messages. Heavy output works best for short horror captions or jokes. If an app trims the text, displays boxes, or makes the line height too tall, reduce the top and bottom marks.

## Accessibility note

Heavy cursed text can be difficult for screen readers and uncomfortable to read. Keep important information in plain text, use cursed styling only for decoration, and switch to clean mode when you need to recover readable text from a copied Zalgo string.
