## Privacy overview

Contrast Check is built so the color contrast checker runs locally in your browser. The tool does not require an account, upload, or server-side color processing.

## Color inputs

Raw color inputs are not collected by this tool. This includes:

- Foreground colors.
- Background colors.
- Pasted HEX or RGB strings.
- Copied contrast reports.

These values are used in your browser to calculate the result shown on the page.

## Analytics

If analytics are enabled in the future, events should only use safe fields such as locale, action, and pass/fail status. Raw foreground and background colors should not be included in analytics events.

## Contact

For privacy questions or correction requests, contact `contact@colorcontrastchecker.online`.
