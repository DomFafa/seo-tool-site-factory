## Privacy

Random Date Generator is designed so the core date generation happens in your browser. The selected start date, end date, weekday choices, and generated results do not need to be sent to a server for the tool to work.

## Analytics policy

Analytics, when enabled for a reviewed production site, should use safe fields only. Raw selected ranges, generated date lists, typed text, uploaded content, and other user-provided values must not be included in analytics events.

## Local processing

The browser calculates eligible dates, applies filters, and formats the output locally. Copying results uses your browser's clipboard features.
