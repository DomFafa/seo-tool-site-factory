# UX Specification: {tool_name}

## 1. UX Goal

Make the user feel that this tool is faster, clearer, and more reliable than the pages currently ranking for `{primary_keyword}`.

## 2. Above-the-Fold Layout

Required elements:

- H1
- Short value proposition
- Primary input
- Result/output area
- Primary action or instant preview
- Copy/download/reset controls when relevant
- Example starter chips
- Privacy reassurance if users enter sensitive text/files

## 3. Primary Task Path

The ideal task path should be:

1. Land on page.
2. Paste or enter input.
3. See result.
4. Copy or use result.

Target: complete the core task in under 3 interactions.

## 5. Mobile UX

- No horizontal scrolling.
- Input and output remain easy to compare.
- Buttons use comfortable touch targets.
- Copy/reset actions are not hidden.
- Explanatory content comes after the tool.

## 6. Accessibility

- Visible labels for fields.
- Accessible names for icon buttons.
- Keyboard-operable controls.
- Visible focus states.
- Clear result change feedback.
- No keyboard traps.

## 7. Ad Placement Rules

- No ads near primary actions.
- No ads inside the result panel.
- No ads that shift the tool after interaction.
- No popup before task completion.

## 10. Quality Checklist

- Tool visible early.
- Main task is obvious.
- Inputs that determine the main result are visible by default.
- Main result label explains what the result represents.
- Users can tell which inputs change the main result and which inputs affect secondary planning/output only.
- Examples are useful.
- Copy action is reliable.
- Copy/export is disabled when the result is invalid or misleading.
- Mobile layout is usable.
- Privacy note is close to the tool.
- Page does not feel like a thin template.
