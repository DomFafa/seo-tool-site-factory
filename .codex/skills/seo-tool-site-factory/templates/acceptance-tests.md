## UX Tests

- Tool appears above the fold on 390px mobile width.
- User can complete the primary task without login.
- User can paste/input and copy/use output without excessive scrolling.
- Copy success state appears when relevant.
- Buttons are large enough for touch.
- No intrusive popup appears before task completion.
- Page does not shift when result appears.
- Ads are not placed near primary actions.

## SEO Tests

- Title exists.
- Meta description exists.
- H1 exists once.
- Canonical exists.
- robots.txt is generated by the factory.
- sitemap.xml is generated by the factory.
- Open Graph tags exist.
- Structured data is valid and matches visible content.
- Draft site keeps indexing disabled.

## Accessibility Tests

- Inputs have visible labels.
- Buttons have accessible names.
- Page can be used with keyboard.
- Focus state is visible.
- Result changes are understandable.
- Color contrast uses accessible defaults.

## Design Tests

- `design-direction.md` exists and names a specific visual personality.
- `design-review.md` records the pre-implementation design review or explains why it was skipped.
- Post-UI `design-review` was run after meaningful UI changes, or `Deferred:` explains why it was not run.
- `qa` or `qa-only` was run when interactions changed, or `Deferred:` explains why it was not run.
- `layout.config.yaml` reflects the selected layout recipe and block order.
- `theme.config.yaml` reflects the selected typography, color, density, and surface strategy.
- The above-the-fold UI does not use a generic centered hero plus three feature cards.
- The UI is visibly differentiated from similar existing factory sites.
- Mobile layout matches the design direction at 390px width.

## Performance Tests

- `pnpm perf audit {site_id}` has no severe warning.
- `benchmark` was run before launch or after large CSS/JS/dependency changes, or `Deferred:` explains why it was not run.
- No unnecessary heavy dependency is added.
- Tool remains responsive during normal input.
- Result panel does not cause layout shift.
