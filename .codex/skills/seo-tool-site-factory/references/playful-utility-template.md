# Playful Utility Tool Template Family

Use this reference when a new SEO utility site can benefit from the successful `weighted-grade-calculator` visual direction.

## Purpose

The final `weighted-grade-calculator` UI established a reusable template family for friendly SEO tools. It should be treated as a design system direction, not a cloneable page skin.

## Best Fit

Good fit:

- calculator
- checker
- analyzer
- planner
- simple converter
- utility helper

Poor fit:

- serious finance, medical, or legal tools
- dense B2B dashboards
- large table workflows
- minimalist brand/product pages

## Core Visual Language

Reusable elements:

- Clean white header.
- Blue brand mark.
- Orange primary CTA.
- Blue secondary action.
- Tool-first first viewport.
- Central framed tool surface.
- Blue dashed or drawn border.
- Warm pale background shape.
- Lightweight cartoon utility/document illustration.
- SEO content below the core tool.
- Restrained headline scale.

## Anti-Clone Rule

Do not copy the exact same first viewport, tool frame, illustration placement, block order, or button/result composition across sites.

Each site using this family must change at least 2-3 of these dimensions:

```text
1. Layout composition
2. Tool interaction model
3. Result display pattern
4. Illustration/theme metaphor
5. Section order
6. Color token emphasis
7. Input density
8. Mobile interaction pattern
```

## Suggested Sub-Templates

```text
playful-dashed-center:
  Centered dashed tool card, compact hero, examples below.

playful-split-tool:
  Input and result split across two columns, stacked on mobile.

playful-result-dashboard:
  Primary result metric plus smaller supporting status cards.

playful-step-wizard:
  Multi-step task flow for tools where users need guided input.

playful-paper-editor:
  Worksheet or document-like editor surface with friendly accents.

playful-compact-mobile-first:
  Small-screen-first tool with minimal header and immediate controls.
```

## Implementation Guidance

- Keep the tool's real job visible before ornamental content.
- Keep input-result causality obvious.
- Avoid oversized Apple-like product typography unless the keyword specifically benefits from it.
- Use cartoon accents as light context, not as the main content.
- Push SEO guide content below the functional tool, not before it.
